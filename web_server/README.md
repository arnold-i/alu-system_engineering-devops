# web_server

Scripts for transferring files to a server and configuring nginx.

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a server's home directory with scp |
| `1-install_nginx_web_server` | Installs nginx and serves a page containing "Holberton School" |
| `2-setup_a_domain_name` | The project's domain name |
| `3-redirection` | Adds a 301 redirect on `/redirect_me` |
| `4-not_found_page_404` | Adds a custom 404 page |
| `5-design_a_beautiful_404_page.html` | A designed 404 page |

Scripts 1, 3 and 4 are run on the server itself, as root.
